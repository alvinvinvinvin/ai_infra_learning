# Valuable Lessons Learned
Latest hardware (e.g., RTX 50 series) requires PyTorch Nightly or source builds

vLLM evolves rapidly; when facing compatibility issues, upgrade first

WSL2, though not officially recommended, can handle deep learning inference well with proper toolchain configuration

Patience in reading error logs and solving issues one by one is a core skill for AI Infra engineers
